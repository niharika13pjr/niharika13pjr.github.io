# Niharika P. Pujari — Personal Website

A simple, single-page personal website built with plain HTML and CSS. It has no framework, package manager, or build step and is ready for GitHub Pages.

## Edit locally

1. Open `index.html` to update page content and links.
2. Open `styles.css` to update colors, type, spacing, or layout.
3. Double-click `index.html` to preview it in a browser, or serve the folder with any simple local web server.

Changes pushed to the repository's publishing branch will be served by GitHub Pages once Pages is enabled in the repository settings.

## Content placeholders

Publication, speaking, and writing entries are intentionally marked as placeholders. Replace the placeholder labels and descriptions in `index.html` when final details are available.
